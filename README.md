
# Anas AI Skills

A collection of reusable AI agent skills designed to improve software development workflows.

## Available Skills

### Laravel Code Reviewer

An AI-powered skill that helps developers review Laravel PHP applications.

### Features

- Detect potential security vulnerabilities
- Identify bugs and logical errors
- Review Laravel best practices
- Optimize Eloquent database queries
- Improve code readability and maintainability
- Suggest testing strategies
- Provide actionable code review reports

## Installation

Install the skill using the Skills CLI:

```bash
npx skills add anasshaath/anas-ai-skills
```

## Usage

After installation, ask your AI coding agent:

"Review my Laravel project for security vulnerabilities, performance issues, and code quality using the laravel-code-reviewer skill."
